# blx Atlas

A Windows addon manager for **World of Warcraft**, initially focused on **WoW Forever**.

**Website:** https://atlas.blixa.dev/

Atlas is a free, non-commercial hobby project by blixa. This public repository contains project information only. The desktop application’s source code is currently private.

## Scope

- Manage a local addon library and enable or disable addons.
- Browse a small starter catalog from addon authors’ GitHub releases.
- Install compatible addon packages and import ZIP files.
- Back up addon files before changes and restore previous backups.
- Install the optional TrailHUD addon and use a separate Windows companion for live media and Wi-Fi information.

## CurseForge integration

Full CurseForge catalog search and download support is under development and requires approved API access. It has not yet been validated with an approved API key. Downloads must respect each author’s third-party distribution settings and use authorized sources. API keys and other credentials will not be published in this repository.

## Current status

Local development builds exist. There is no public release yet, and features may change. The website is currently hosted on the developer’s own computer, so it may be unavailable while that computer is offline.

Atlas is an independent project and is not affiliated with Blizzard Entertainment, CurseForge, or Overwolf.
